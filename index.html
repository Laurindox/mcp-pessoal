MCP Pessoal

Ferramenta de uso próprio, de um único usuário.

O que é

Uma integração que liga meu assistente de código local à minha própria conta Google, para ler e organizar arquivos do meu Drive e mensagens do meu Gmail enquanto trabalho. Roda no meu computador, via Model Context Protocol.

Quem usa

Só eu, Adlem Laurindo, na conta adlensilva4@gmail.com. Não há cadastro, não há outros usuários e o aplicativo não é distribuído.

O que ele acessa

  • Arquivos do meu Google Drive (leitura e edição de documentos e planilhas meus)
  • Mensagens do meu Gmail (leitura, para consultar recibos e faturas)
  • Meu Google Agenda, para ver e criar eventos meus

Onde os dados ficam

Na minha máquina. Não existe servidor, banco de dados nem terceiro envolvido: o programa fala direto com a API do Google a partir do meu computador.
